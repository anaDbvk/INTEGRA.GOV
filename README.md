# INTEGRA.GOV · Moving to Poland

A mobile-first web app that helps newcomers to Poland plan official tasks
(residence permit, PESEL, address registration, NFZ, ZUS, taxes, business…).
A chat assistant researches **official Polish websites live** and turns the
answer into a step-by-step journey with cited sources. Users can also build and
edit their own journeys, track progress and see in-app reminders.

Live: <https://moving-to-poland.onrender.com>

![INTEGRA.GOV architecture](docs/architecture.png)

## Features

- **Assistant chat**: asks one follow-up question at a time, then creates a
  journey whose steps each cite an official page.
- **Journeys**: assistant-created or self-built (name, target date, up to 20
  steps with notes and deadlines). You can reorder, add and remove steps and
  track progress.
- **Explore, Alerts, Profile**: category browsing, in-app reminders, display
  preferences.
- **Languages**: English, Polish and Ukrainian (`webapp/static/i18n.js`). The
  app follows the phone's language, and users can switch with the globe button
  or in Profile › Preferences. The assistant replies in the same language.
- **Navigation**: the phone's Back button follows in-app navigation (History
  API).
- **Privacy**: Profile › Privacy has *Download my data* and *Delete my data*.

### How the assistant works

Each chat turn makes two Anthropic calls:

1. **Research.** Claude uses the web search tool (`web_search_20250305`) and
   can only search the approved official domains. The backend discards results
   from other domains and any non-HTTPS URLs.
2. **Journey.** Claude must call the `return_journey_step` tool. It either asks
   one follow-up question or returns steps, and every step must cite a
   researched source.

The approved domains come from the Supabase `sources` table (rows with
`assistant_enabled = true`). The list is cached for 5 minutes, and
`WEB_SEARCH_DOMAINS` is the fallback. To add a site, insert a row into
`sources`. To stop searching a site, set `assistant_enabled = false`.

Web search costs $10 per 1,000 searches plus tokens. Web search must be enabled
for your organisation in the Anthropic Console.

## Setup

### 1. Supabase

In the Supabase SQL Editor, run `supabase/schema.sql`, then
`supabase/app_tables.sql`. Both scripts are safe to re-run, so re-run them
after updates. Row-level security is enabled without public policies, so only
the server (through `DATABASE_URL`) can access the data.

Use the **Session pooler** connection string (IPv4) as `DATABASE_URL`.

### 2. Render

Create a Blueprint from this repository; it uses `render.yaml`. Alternatively,
create a Python web service with:

- build command: `pip install -r requirements.txt`
- start command: `uvicorn webapp.app:app --host 0.0.0.0 --port $PORT`
- health check path: `/health`

With the Blueprint, Render deploys only after CI passes
(`autoDeployTrigger: checksPass`). If you created the service manually, set
**Settings › Build & Deploy › Auto-Deploy** to *After CI Checks Pass*.

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | Supabase Session pooler connection string |
| `APP_SESSION_SECRET` | Stable random secret of at least 32 characters. Changing it means existing phone hashes no longer match. |
| `ANTHROPIC_API_KEY` | Server-side Anthropic API key |
| `ANTHROPIC_MODEL` | Claude model ID (e.g. Haiku 4.5) |
| `ANTHROPIC_FAST_MODEL` | Optional model for the research step. Defaults to `ANTHROPIC_MODEL`. |
| `WEB_SEARCH_DOMAINS` | Fallback domain allowlist, used when the `sources` table is unavailable |
| `WEB_SEARCH_MAX_USES` | Web searches per chat turn (1–8, default `3`) |
| `RATE_LIMIT_PER_MINUTE` | Per-IP limit for interview and session requests (default `10`, in memory) |
| `ASSISTANT_DAILY_LIMIT` | Assistant messages per profile per UTC day (default `50`; `0` disables). Counted in `assistant_usage`. |
| `DB_POOL_MAX` | Pooled Supabase connections per instance (default `5`) |

Never put credentials in the browser or the repository. Set a monthly spend
limit in the Anthropic Console.

### 3. Run locally

```powershell
python -m pip install -r requirements.txt
$env:DATABASE_URL = "your-Supabase-Session-pooler-connection-string"
$env:APP_SESSION_SECRET = "a-stable-random-secret-at-least-32-characters"
$env:ANTHROPIC_API_KEY = "your-Anthropic-API-key"
$env:ANTHROPIC_MODEL = "your-enabled-model-id"
python -m uvicorn webapp.app:app --host 127.0.0.1 --port 8000
```

Then open <http://127.0.0.1:8000>.

## Security and privacy

- **Security headers:** Content-Security-Policy (scripts only from this site,
  no framing), HSTS over HTTPS, `X-Frame-Options`, `X-Content-Type-Options`,
  `Referrer-Policy`, `Permissions-Policy`. API responses use
  `Cache-Control: no-store`.
- **Guest profiles:** the phone number is stored only as an HMAC hash.
  Profiles are tied to the browser with HttpOnly device and session cookies.
  Sessions expire after 15 days without activity. The phone number is **not
  verified**, so it is an identifier, not proof of identity.
- **Your data:** `GET /api/me/export` returns JSON without hashes.
  `DELETE /api/me` removes the profile and everything linked to it (via
  `on delete cascade`).
- **What goes to Anthropic:** questions are sent to Anthropic. Users should not
  enter PESEL numbers, document numbers, exact addresses or other sensitive
  data.
- **Reminders:** in-app only; no email or push notifications.
- **Official facts:** always check them on the linked official page.

## Optional: scraper

The assistant no longer needs scraped data. `scraper/` remains for snapshots of
official pages, in case you want them:

```powershell
$env:MAX_PAGES = "100"; $env:SOURCES_ONLY = "migrant"
python scraper/pl_gov_scraper.py                     # writes pl_gov_pages.jsonl
python scraper/load_to_supabase.py pl_gov_pages.jsonl  # needs DATABASE_URL
```

You can also run it from GitHub: **Actions › Scrape Polish government and city
pages › Run workflow**. This workflow is manual only and needs the
`DATABASE_URL` Actions secret (Session pooler).

The scraper:

- respects `robots.txt`
- does not run JavaScript
- redacts PII on a best-effort basis (emails, phone numbers, IDs, but not names)
